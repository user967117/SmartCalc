## Опис додатка
SmartCalc — це веб-додаток, розроблений для демонстрації навичок побудови сучасних статичних інтерфейсів. Основний акцент зроблено на забезпеченні адаптивності (Responsive Web Design) та дотриманні принципів зручності користувацького інтерфейсу.

### Функціональні особливості:
- Режим Standard: призначений для базових арифметичних операцій.
- Режим Programmer: забезпечує роботу з системами числення (Hex, Dec, Oct, Bin) та побітовими логічними операціями.
- Адаптивність: інтерфейс коректно відображається на настільних комп'ютерах, планшетах та смартфонах.
- Дизайн: реалізовано сучасну темну тему на базі фреймворку Bootstrap 5.

## Технологічний стек
- HTML5: структура та семантична розмітка контенту.
- CSS3: кастомна стилізація, використання Flexbox та медіа-запитів.
- Bootstrap 5: побудова адаптивної сітки, компонентів навігації та форм.
- Google Fonts: типографіка для покращення читабельності інтерфейсу.

## Структура проєкту
Проєкт включає 5 основних сторінок:
1. index.html — Головна робоча сторінка з інтерфейсом калькулятора.
2. about.html — Інформаційна сторінка з описом проєкту та технологій.
3. profile.html — Кабінет користувача з табличним представленням даних.
4. login.html — Форма авторизації користувача.
5. register.html — Форма реєстрації нового облікового запису.

## Схема навігації
Сайт має лінійну структуру навігації через спільну панель заголовка (Header):
Головна (Калькулятор) <-> Про додаток <-> Профіль <-> Вхід <-> Реєстрація

## Встановлення та запуск
1. Клонуйте репозиторій:
   git clone https://github.com/username/SmartCalc.git
2. Перейдіть у директорію проєкту:
   cd SmartCalc
3. Відкрийте файл index.html у будь-якому сучасному веб-браузері.
